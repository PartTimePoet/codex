ℹ About Sentinel

Sentinel is a user activity anomaly detection system designed to identify suspicious behavior across login patterns, device usage, and data access. It helps organizations proactively detect threats, reduce risk, and improve security awareness.

Features include real-time anomaly detection, risk scoring, session tracking, and security reporting.
